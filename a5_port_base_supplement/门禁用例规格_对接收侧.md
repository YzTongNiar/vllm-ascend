# FIA v2 Sink 设备门禁用例规格（对接收侧，自包含）

> 目的：接收侧在**自己的构建/环境**上构造并执行以下用例，以官方算子为基准做验收。
> 本文档自包含：全部参数显式给出，无需依赖我方脚本；文末附我方参考实现位置（可选阅读）。
> 版本基准：与 round_5 结档态算子等价（含 104 tiling key 族、(192,0,192) 路由臂、L0B 分块修复）。

## 0. 通用约定（所有用例）

| 项 | 约定 |
|---|---|
| 调用形态 | 两段式：先 metadata（device 读 seq_len 算分核），再主算子（必带 meta_data） |
| seq 语义 | **actual_seq_qlen 传累计值** `[q0, q0+q1, …]`；actual_seq_kvlen 传逐请求值——传错=非首请求输出全零（无报错，最大坑） |
| 官方对照 | `torch_npu.npu_fused_infer_attention_score_v2`（host list 传 seq），同参同输入 |
| 判定 | `torch.equal(sink_out, official_out)`（bit 级）；B≥2 用官方逐请求 B=1 输出 concat 作参照（官方对部分形态拒 B≥2） |
| 环境 | ASCEND_CUSTOM_OPP_PATH 双条目指向被测 OPP 包（vendors 目录 + 其父 packages 目录两条） |

## 1. 门禁用例规格

### G1 mqa_c27（D192 GQA g=1 核心验收）

| 参数 | 值 |
|---|---|
| 形态 | B=1；query [7, 8, 192] bf16，TND；K/V PA 池 [2, 8, 128, 192] bf16（pool=⌈kvlen/128⌉+2）；block_table [1,1]=[[0]]；block_size=128 |
| 头数 | num_query_heads=8，num_key_value_heads=8（MHA g=1） |
| seq | actual_seq_qlen=[7]，actual_seq_kvlen=[20] |
| 其他 | sparse_mode=0；scale=1/√192；rope 无（rope_head_dim=0） |
| 验收 | sink 输出 vs 官方 **bit_exact=True**（torch.equal） |

### G2 mqa_c28（D128 防回归）

同 G1，仅 head_dim 192→128（K/V 池 [2,8,128,128]）。验收 bit_exact=True。

### G3 C21（GQA fp16 gS=2 混合变长回归）

| 参数 | 值 |
|---|---|
| 形态 | B=8；N1=16，N2=8（g=2）；D=128；**fp16**；TND；PA 池 4 维；BS=128；sm=0 |
| qlen（逐请求） | [8,7,9,6,8,10,5,7]（T=60，累计 [8,15,24,30,38,48,53,60]） |
| kvlen（逐请求） | [77,129,130,4096,4097,16,128,8192]（bt_w=64） |
| 验收 | sink vs 官方（host list 传 seq）bit_exact=True |

### G4 kvlen 长序列扫描（D192 g=1 B=1）

kvlen ∈ {4096, 32768}，其余同 G1。验收 bit_exact=True（覆盖 L0B 修复后的长序列包络）。

### G5 B=2 多请求（等长）

D192；B=2，两请求各 qlen=7、kvlen=248；累计 q-len=[7,14]；block_table 两行各 2 页（页号连续互异）。
验收：sink B=2 单次输出 vs 官方逐请求 B=1 输出 concat，bit_exact=True。

### G6 C01（MLA MTP-verify 形态，PR 新接 MLA 面）

| 参数 | 值 |
|---|---|
| 形态 | B=8；T=64（每请求 8 token）；N1=16，N2=1（MLA）；D=512 + rope=64 分离传输；**bf16** |
| KV 池 | 4 维 [3870, 1, 128, 512] + rope 池 [3870, 1, 128, 64]；block_table [8, 3126]；BS=128 |
| mask | atten_mask [2048, 2048] INT8 + sparse_mode=3 |
| qlen（累计） | [8,16,…,64]；kvlen（逐请求）[4096,4160,…,4544] |
| 验收 | vs 官方（同参含 mask/rope）输出 bit 一致或 finite+shape 正确（MLA 面可按贵侧口径定 bit/MERE） |

### G7（抽轴）gS ∈ {2,4,6,8} × D192

D192、B=2 等长、kvlen 248；N2=8（gS=8 时 N2=12，N1=N2×gS）。验收同 G5。

## 2. 已知行为注记（非缺陷，判读时注意）

1. D192 × **B≥2** × kvlen≥~4K：FD 分块负载均衡与官方 B=1 存在差异 → fp32 归约序差
   mere ~2e-05（≪ bf16 分辨率 3.9e-3）。bit 判定在该象限会 False，属已知归约序差，
   建议该象限以 MERE ≤ 1e-4 或逐元素 max_abs ≤ 1 bf16 ULP 口径验收。
2. 跨流覆盖 metadata 输入会污染分核计划（竞态设备实测可复现）——测试脚本若复用
   qlen/kvlen buffer，须保证写与 AICPU 读同流，或每 call clone（官方 wrapper 的
   per-call clone 即此防御）。
3. metadata 输出为 device GM 上 uint32[1024] 定长任务书（非 list）；解码布局见
   接口文档 §4.1.1。
